# 🗒️ NOTES-BACKEND

A simple and efficient backend for a Notes app built using **Node.js**, **Express.js**, and **MongoDB**. This API allows users to manage personal notes securely.

## 🚀 Features

- 📝 CRUD operations for notes
- 🔒 Passwords hashed with bcrypt
- 🌐 RESTful API design
- 📁 Organized code structure

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose ODM
- **Environment Variables:** dotenv
